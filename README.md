# منصة التحدي · مدار 2026

باك إند **ASP.NET Core (.NET 8 / C#)** + واجهات **HTML/JS** بهوية مدار، تُقدَّم من الخادم نفسه.

## الصفحات
| الرابط | الاستخدام |
|---|---|
| `/` | واجهة المتسابق (جوال). `?orbit=pos\|idn\|jdg\|trt` يحدد المدار مسبقًا |
| `/screen.html?orbit=idn` | شاشة المحطة (مؤشر): QR + لوحة الصدارة الحيّة + عدّادات |
| `/admin.html` | لوحة التحكم (رمز سري): إحصاءات، أصعب الأسئلة، QR لكل مدار، لون الشارة، إخفاء أسماء، توصيات منصات طويق، تصدير CSV |

## التشغيل
```bash
dotnet run                      # http://localhost:5000
MADAR_ADMIN_PIN=123456 dotnet run
```
Docker: `docker build -t madar . && docker run -p 8080:8080 -v madar-data:/data -e MADAR_ADMIN_PIN=123456 madar`

| متغير | الوصف |
|---|---|
| `MADAR_ADMIN_PIN` | رمز لوحة التحكم (الافتراضي 2026، غيّره) |
| `MADAR_DATA_DIR` | مكان حفظ النتائج (`rounds.jsonl`) والإعدادات؛ اجعله مجلدًا دائمًا |
| `MADAR_CORS_ORIGINS` | عند استضافة الواجهة منفصلة، وضع رابط الواجهة هنا، ورابط الـ API في `wwwroot/js/config.js` |

## بعد النشر
1. افتح `/admin.html` واكتب **رابط الاستضافة العام** (يحمله الـ QR).
2. اطبع/اعرض QR كل مدار من اللوحة على شاشة المحطة المناسبة.
3. افتح `/screen.html?orbit=…` على شاشة كل محطة.

## كيف تعمل الجولة
- الأسئلة تُسحب عشوائيًا **على الخادم** لكل متسابق من (المجال × المدار) بحسب المستوى: **12 / 15 / 15** سؤالًا، ويُخلط ترتيب الخيارات.
- الإجابة الصحيحة لا تصل المتصفح قبل الإجابة؛ والنقاط والوقت يحسبهما الخادم: 100 للصحيحة + حتى 50 مكافأة سرعة (مهلة السؤال 20 ثانية).
- المجالان: «الذكاء الاصطناعي وعلم البيانات» و«الوعي والأمن السيبراني».

## بنك الأسئلة
`Data/questions.json`: 192 سؤالًا (24 لكل مدار في كل مجال)، كل سؤال يحمل رمز المحطة المصدر (مثل `B3-11`) من ملفات «محتوى مدار» الرسمية. التوصيات في `Data/recs.json` (روابط سطر ومكتبة طويق وتحديات طويق).

## ملاحظات
- التخزين ملف JSON Lines بلا قاعدة بيانات خارجية: يكفي لعشرات الآلاف من الجولات على خادم واحد. لعدة خوادم استبدل `Store.cs` بـ SQL Server/PostgreSQL.
- الجلسات الجارية في الذاكرة: إعادة تشغيل الخادم تُنهي الجولات الجارية فقط، وتبقى النتائج المحفوظة.
- Netlify لا يشغّل .NET: استضف الخادم على Azure App Service أو Render/Railway/Fly عبر Docker أو أي VPS.
- اختبار سريع: شغّل الخادم على `127.0.0.1:5080` ثم `python3 tests/api_smoke_test.py`.
